文楷、朱雀仿宋和新晰黑使用发行版 TrueType 文件，由 FontTools 的 `ttLib.woff2 compress` 转为 WOFF2。IPAex Gothic 使用原始发行文件。

要用原始 IPA 字体写日记，请在「设置」的「外观与称呼」中展开「字体与许可」，选择「将日记字体设为 IPAex 原版」。
